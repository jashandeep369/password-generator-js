# 🔐 Password Generator

A modern and responsive password generator built using HTML, CSS, and JavaScript.

## 📖 About The Project

This application generates secure random passwords with a single click. The project was created to practice JavaScript fundamentals, DOM manipulation, and user interface design while building a practical real-world tool.

## ✨ Features

- Generate random passwords
- Instant password creation
- Clean modern UI
- Responsive layout
- Simple and easy to use

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 🧠 Concepts Practiced

- Functions
- Variables
- Arrays
- Random Number Generation
- DOM Manipulation
- Event Handling
- String Handling

## 🚀 How To Run

1. Clone the repository

```bash
git clone https://github.com/yourusername/password-generator-js.git
```

2. Open the project folder

3. Open `index.html` in your browser
